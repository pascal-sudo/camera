BUILD THE APK WITHOUT ANDROID STUDIO
1. Create a free GitHub account and a new repository (private is fine).
2. Upload ALL files from this folder (keep the .github folder) and commit.
3. Open the repo's "Actions" tab -> "Build APK" -> wait ~3-5 minutes.
4. Open the finished run, download the "camera-preview-apk" artifact (a zip), unzip it.
5. Copy app-debug.apk to your phone and install it (allow "install unknown apps").
